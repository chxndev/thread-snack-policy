thread-snack 개인정보처리방침

최종 수정일: 2026년 8월 12일

thread-snack(이하 “본 앱”)은 개인이 혼자 사용하기 위해 만든 비상업적 도구입니다. 본 앱은 운영자 본인의 컴퓨터에서만 실행되며, 공개된 Threads 게시물을 모아 요약해 운영자 본인의 비공개 Discord 채널로 보냅니다. 이 문서는 본 앱이 어떤 데이터를 다루는지, 어디에 보관하는지, 어떻게 삭제할 수 있는지를 설명합니다.

1. 운영 주체와 이용 범위

  • 본 앱에는 회원가입이 없고, 운영자 외의 이용자가 없습니다.
  • 본 앱은 웹사이트나 공개 서비스를 제공하지 않습니다. 운영자의 로컬 네트워크(127.0.0.1)에서만 접근 가능합니다.
  • 본 앱은 광고를 게재하지 않으며, 어떤 데이터도 판매·대여·거래하지 않습니다.

2. 수집하는 정보

구분내용출처
공개 게시물 게시물 ID, 본문, 작성자 사용자명, 게시 시각, 공개 링크, 공개 반응 수(좋아요·답글·리포스트) Threads 공개 RSS 피드 및 Threads API
운영자 계정 정보 Threads 액세스 토큰, 토큰 만료 시각 운영자가 직접 발급해 입력
실행 기록 수집·전송 시각, 성공/실패 상태, 건수 본 앱이 생성

본 앱은 비공개 게시물, 다이렉트 메시지, 이메일 주소, 전화번호, 결제 정보, 위치 정보, 기기 식별자를 수집하지 않습니다. 쿠키나 추적 기술을 사용하지 않습니다.

3. 이용 목적

수집한 공개 게시물은 운영자 본인이 읽기 위한 요약본을 만드는 용도로만 사용됩니다. 같은 내용을 여러 번 보내지 않기 위해 이미 보낸 게시물의 식별자를 기록하며, 나중에 다시 찾아보기 위해 본문을 보관합니다. 프로파일링이나 자동화된 의사결정에 사용하지 않습니다.

4. 보관 장소와 기간

  • 모든 데이터는 운영자 컴퓨터의 로컬 SQLite 데이터베이스 파일 하나에 저장됩니다.
  • 외부 데이터베이스, 클라우드 저장소, 분석 서비스를 사용하지 않습니다.
  • 보관 기간에 정해진 상한은 없으며, 운영자가 언제든 파일을 삭제할 수 있습니다(삭제 방법).

5. 제3자 제공

본 앱은 데이터를 제3자에게 제공하지 않습니다. 다만 동작상 다음 서비스와 통신합니다.

대상전송되는 것목적
Threads (Meta)액세스 토큰, 검색어공개 게시물 조회
Open RSS조회할 공개 계정명자격증명 없이 공개 게시물 조회
Discord수집한 공개 게시물의 요약과 본문운영자 본인의 비공개 채널로 전달
Anthropic Claude수집한 공개 게시물 본문한국어 요약 생성

각 서비스의 데이터 처리에는 해당 서비스의 정책이 적용됩니다. Discord로 전송된 내용은 운영자 본인만 접근할 수 있는 비공개 채널에 남습니다.

6. 게시물 작성자의 권리

본 앱은 공개된 게시물만 다룹니다. 자신의 게시물이 본 앱에 보관되는 것을 원하지 않는 Threads 이용자는 아래 문서의 안내에 따라 삭제를 요청할 수 있으며, 요청 시 해당 작성자의 데이터를 지체 없이 삭제합니다.

7. 보안

  • 액세스 토큰과 웹훅 주소는 버전 관리에서 제외된 환경 파일과 로컬 데이터베이스에만 저장됩니다.
  • 로그를 남길 때 토큰과 웹훅 비밀 부분은 가려집니다.
  • 본 앱의 웹 인터페이스는 외부에 공개되지 않습니다.

8. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

9. 방침 변경

본 방침이 바뀌면 이 페이지를 갱신하고 상단의 최종 수정일을 고칩니다.

10. 문의
