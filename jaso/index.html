설정

이 페이지는 claude.ai 안에서 실행 중이며, 보는 사람의 claude.ai 구독 사용량으로 Claude를 호출합니다. API 키가 필요 없습니다.
이 페이지는 운영자의 PC에서 운영자의 claude.ai 구독으로 Claude를 호출합니다. 입력한 내용은 운영자의 서버를 거쳐 Claude로 전달되며 서버에 저장되지는 않습니다. 기기 간 동기화를 켜면 이 브라우저에서 암호화한 사본만 서버에 보관됩니다.
이 브라우저에만 저장됩니다.
기기 간 동기화
