사용자 데이터 삭제 안내

thread-snack · 최종 수정일 2026년 8월 12일

thread-snack은 개인이 혼자 사용하는 비상업적 도구입니다. 회원가입이 없고, 운영자 본인 외에 이용자가 없으며, 모든 데이터는 운영자 컴퓨터의 로컬 데이터베이스 파일 하나에만 저장됩니다. 이 문서는 그 데이터를 삭제하는 방법을 설명합니다.

보관되는 데이터

  • 공개 Threads 게시물의 본문·작성자 사용자명·게시 시각·공개 링크·공개 반응 수
  • 중복 전송을 막기 위한 게시물 식별자 기록
  • 운영자 본인의 Threads 액세스 토큰
  • 실행 이력(시각·성공 여부·건수)

비공개 게시물, 메시지, 이메일, 전화번호, 결제 정보는 보관하지 않습니다.

1. 게시물 작성자가 삭제를 요청하는 경우

자신이 작성한 공개 Threads 게시물이 thread-snack에 보관되는 것을 원하지 않는다면, 아래 중 한 가지 방법으로 요청해 주세요. 요청을 확인하는 즉시 해당 작성자의 데이터를 전부 삭제하고 이후 수집 대상에서 제외합니다.

  1. GitHub 이슈로 요청: github.com/chxndev/thread-snack-policy/issues/new
  2. 제목에 데이터 삭제 요청이라고 적고, 본문에 해당 Threads 사용자명(@ 포함)을 적어 주세요.
확인 절차
본인 확인을 위해, 요청하신 Threads 계정에서 확인 가능한 방법(예: 해당 계정으로 올린 게시물 링크)을 함께 알려 주시면 처리가 빠릅니다. 처리 완료 시 해당 이슈에 답변을 남깁니다.

2. Meta 계정 연결을 끊는 경우

Threads 설정에서 이 앱의 접근 권한을 철회하면 thread-snack은 더 이상 Threads API로 데이터를 가져올 수 없습니다.

  1. threads.net/settings/account 접속
  2. 웹사이트 권한 항목에서 thread-snack 연결 해제

연결을 끊어도 이미 보관된 데이터는 남으므로, 그 삭제까지 원한다면 위 1번 방법으로 요청해 주세요.

3. 운영자가 전체 데이터를 삭제하는 방법

운영자는 아래 명령으로 저장된 데이터 전부를 즉시 삭제할 수 있습니다.

systemctl --user stop thread-snack.service
rm ~/work/chxnProj/thread-snack/threadsnack/data/threadsnack.db
systemctl --user start thread-snack.service

이 파일이 유일한 저장소이므로, 삭제하면 수집한 게시물·전송 기록·토큰이 모두 사라집니다. 앱은 다음 실행에서 빈 데이터베이스를 새로 만듭니다.

처리 기한

삭제 요청은 확인 후 7일 이내에 처리합니다.
